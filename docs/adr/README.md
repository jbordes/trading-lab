# Registros de decisiones arquitectónicas

Los ADR conservan decisiones durables, sus alternativas y consecuencias. La arquitectura describe el estado vigente y las bitácoras registran el contexto cronológico.

## Convención

- Nombre: `NNNN-<tema-en-kebab-case>.md`.
- Estados admitidos: `proposed`, `accepted`, `superseded` y `rejected`.
- Un ADR aceptado no se reescribe para cambiar la decisión: se crea otro ADR y ambos se enlazan.
- Cada ADR incluye contexto, alternativas consideradas, decisión y consecuencias.

Copiar `_template.md`, asignar el siguiente número disponible y enlazar el ADR desde la sesión y la arquitectura que corresponda.
